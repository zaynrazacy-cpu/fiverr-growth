# FiverrGrowth AI 🚀
### Autonomous Fiverr Growth, Gig SEO & Opportunity Copilot

FiverrGrowth AI is an enterprise-grade, multi-modal growth copilot designed for Fiverr freelancers and digital agencies. It automates niche research, algorithmic SEO gig creation, and Buyer Brief proposal generation using state-of-the-art AI.

---

## 🏗️ Architecture Overview

```
fiverr-growth/
├── frontend/             # React 19 + Tailwind CSS + shadcn/ui + GSAP + Three.js
├── backend/              # Node.js + Express + TypeScript + Swagger/OpenAPI + SQLite/Prisma
├── ai_orchestration/     # Python FastAPI + Groq (Llama 3.3 70B) + Google Gemini 2.0 Flash
└── docs/                 # API Documentation & Architecture Specifications
```

---

## ✨ Core Features

1. **Autonomous Market & Competitor Intelligence:** Analyzes top ranking gigs, average pricing, queue volumes, and discovers low-competition keyword gaps.
2. **Algorithmic 5-Stage Gig Synthesizer:** Crafts click-worthy titles, 5 prioritized search tags, persuasive descriptions, 3-tier pricing (Basic/Standard/Premium), and FAQs.
3. **Buyer Briefs Instant Proposer:** Analyzes client job briefs and synthesizes high-converting, tailored proposals in seconds.
4. **Interactive 3D Glassmorphism Dashboard:** Built with Three.js 3D canvas and GSAP micro-animations for an ultra-premium experience.

## 🚀 Quickstart

### Prerequisites
- Node.js 18+
- Python 3.10+
- Git

### 1. AI Orchestration Engine (Python)
```bash
cd ai_orchestration
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python main.py
```

### 2. Backend Gateway (Node.js)
```bash
cd backend
npm install
npm run dev
# Swagger Docs available at: http://localhost:5000/api/docs
```

### 3. Frontend Dashboard (React + Three.js)
```bash
cd frontend
npm install
npm run dev
# Running at: http://localhost:5173
```

## 🔒 Safety & Anti-Ban Architecture
This software is designed as a **Human-in-the-loop Copilot**. The AI generates 100% of the content and proposals, and the freelancer uses 1-click verified execution, maintaining full compliance with Fiverr Terms of Service and preventing account bans.
